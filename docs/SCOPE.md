# Escopo do Projeto — Flor de Menina

## Cliente
Flor de Menina (Daniela Costa), loja física em Maceió-AL, 13 anos, 293k seguidores Instagram.

## Contrato
- Valor total: R$ 5.900 (50% pago, 50% contra entrega)
- Manutenção pós-entrega: R$ 300/mês

## Manutenção mensal (R$ 300) inclui
- Hospedagem VPS + monitoramento
- 2h/mês de ajustes pequenos
- Correção de bugs do sistema
- Backup diário automático
- Atualizações de segurança

## NÃO incluso na manutenção
- Novas features (orçamento à parte)
- Redesign visual (orçamento à parte)
- Erros de terceiros (MP, Melhor Envio, Correios)
- Treinamento adicional além do inicial

## Funcionalidades contratadas

### Loja pública
- Catálogo com filtros e busca
- Página de produto com variações (tamanho/cor), galeria, tabela de medidas, "compre junto"
- Carrinho com reserva de estoque (15min)
- Checkout multi-step (dados → endereço → frete → pagamento → revisão)
- Pagamento: PIX + Cartão (Mercado Pago)
- Frete: Melhor Envio com regras de frete grátis por região
- Cadastro obrigatório (e-mail/senha + Google)
- Conta do cliente: perfil, endereços, pedidos, histórico
- Wishlist/Favoritos
- Reviews com foto

### Painel admin
- Login com roles (admin, operador)
- Dashboard com métricas básicas
- CRUD produtos com IA pra gerar descrição (OpenRouter)
- CRUD categorias + tabelas de medidas por categoria
- Gestão de estoque com baixa manual (substitui PDV)
- CRUD cupons de desconto
- Gerenciar pedidos (status, rastreio)
- Moderação de reviews
- Páginas institucionais editáveis (Sobre, Trocas, FAQ)

### Notificações
- E-mails transacionais via Resend (pedido criado, pagamento aprovado, enviado, entregue)

## Fora de escopo (combinado com cliente)
- App mobile nativo
- PDV (sistema de venda física com carrinho/comprovante)
- Integração com ERP (Bling, Tiny, Omie)
- CRM
- Programa de fidelidade
- Login Apple
- Newsletter / e-mail marketing
- Multi-loja / multi-tenant
